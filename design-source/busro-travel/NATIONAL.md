# 국토종주 기능 경계

- 검색 API 경로를 여행 티켓에 보관합니다. 국토종주 홈에는 나드리 피드를 노출하지 않습니다.
- 사용자가 시작을 누르면 GPS를 1회 요청합니다. 30초 이내 위치, 오차 0~100m, 정류장과의 거리+오차 200m 이내를 확인합니다. 미래 5초 초과 위치는 거절합니다.
- 저장하는 기기 확인은 `ok`, `checkedAt`, `scope`뿐이며 원본 GPS 좌표는 저장하지 않습니다. 정류장 좌표는 경로 데이터에 포함됩니다.
- GPS와 브라우저 저장소는 위조할 수 있습니다. 이 확인은 탑승·시내버스 이용·전체 여정 완주 증명이 아니며 공식 완주 배지는 잠금 상태입니다.
- 활성 여행 화면에서 현재 승차 구간의 BIS를 60초 간격으로 조회합니다. 숨긴 화면·이탈 시 중단하며, 실패 시 5분 대기합니다. 데이터가 없다는 이유로 운행 종료를 판정하지 않습니다.
- BIS만으로 전체 환승·막차 성공 여부를 판단하지 않습니다. 음식점 API 발급 및 무료 사용 자격은 미확인으로 추천을 제공하지 않습니다.
- 완료는 사용자 수동 기록입니다. 위치 확인 기록과 공식 인증은 별도로 표시합니다.

검증: `node --test location-check.test.js`, `node verify-national.mjs`. 후자는 테스트 전용 GPS·BIS 픽스처이며 실제 탑승 인증 시험이 아닙니다.

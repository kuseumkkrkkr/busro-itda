# 나드리 장소 카탈로그

이 디렉터리의 SQLite DB는 운영자가 편집·배포하는 읽기 전용 추천 원장입니다. 사용자 위치·기록·개인정보는 저장하지 않습니다. 기존 버스 노선 DB/API는 변경하지 않습니다.

- `nadri.seed.json`: 근거를 확인한 장소와 교통 접근 안내. 2026-09-06에 대전 2곳·청주 4곳 등록.
- `nadri.sqlite`: `places`와 `sources` 관계 테이블. 장소 ID 및 출처 URL 복합키, 외래키, 단일 트랜잭션 upsert. 동일 seed 재실행은 중복을 만들지 않음. 제외된 장소는 비공개 전환.
- `nadri.generated.json`: DB에서 공개·비협찬 장소를 조회해 만드는 배포용 스냅샷. 앱은 이를 번들에 포함하므로 추천 조회에 서버/API 호출이나 DB 연결을 사용하지 않음.
- `../build-nadri.mjs`: Node 24의 내장 SQLite로 생성·무결성 검사·내보내기. `npm run build`가 자동 실행.

## 편집 원칙

외곽·자연·전원·역사적 분위기를 중심으로 장소를 선정한다. 도심 카페, 개별 상점, 프랜차이즈, 임의 평점은 넣지 않는다. 순서는 편집 순서이며 개인화 최적 순위가 아니다. 향후 광고는 별도 모델·표시가 필요하며 현재 카탈로그에는 광고가 없다.

`transfers`는 `origin`에서 안내된 접근 경로의 환승 수다. 사용자 위치의 환승 수가 아니며 UI는 개인 환승 수처럼 표시하지 않는다. 막차, 배차 간격, 요금, 영업시간을 추정하지 않는다. 장소 설명은 출처에 근거한 짧은 편집 요약이다. 출처의 의료 효능·옛 시간표·특정 점포 권유는 재사용하지 않는다.

`point`는 장소 중심이 아니라 정류장 좌표다. 운영 `/api/network/stops`에서 `city_code`, `node_id`, `stop_name`, 좌표, `graph_ready`를 확인했다. 이는 장소 입구까지 도보 경로·해당 노선 방향·현재 운행 여부를 보장하지 않는다. 실제 출발/도착 정류장과 방향은 경로 검색에서 선택한다. `graph_ready`는 검토 시점의 스냅샷이며 라이브 검색 결과가 우선한다.

## 검토 기록

- 대청댐: K-water의 72·73번 안내. 대전시 소식 재게시 자료의 주말 종점 변경을 주의사항에 포함. 정류장 노선 연결은 준비 중.
- 장태산: 휴양림 운영기관 숲나들e의 20·22번 안내와 대전시 장소 소개.
- 문의문화유산단지: 청주시 소개, 2026 행사 주최 측의 터미널→311번 안내. 행사 전용 셔틀은 제외. 주최 측 접근 안내임을 명시.
- 상당산성: 청주시 장소 소개와 2026년 대중교통과 답변의 862번. 오래된 관광 페이지 시간표는 제외. 정류장 노선 연결은 준비 중.
- 초정행궁: 청주시 소개와 한국관광공사의 101번 안내. 기사 내 도보 8분은 치유마을에 해당하므로 행궁에 전용하지 않음. 정류장 노선 연결은 준비 중.
- 미동산수목원: 운영기관 이용안내의 833→상당공원→211번. 다른 공식 페이지와 다른 공항·청주역 접근은 싣지 않음.

6곳 모두 출처 URL·검토일을 DB 및 앱 상세 화면에 보관한다. 추가 지역도 동일 기준으로 근거 확인 후 seed를 편집하고 다시 배포한다. 임의 외부 크롤링·실시간 예약·광고 집행 기능은 만들지 않았다.

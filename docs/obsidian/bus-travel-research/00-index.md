# 시내버스 여행 검증 DB

공개 여행기에서 실제로 언급된 연계 사례를 모아 둔 검증 큐다. 이 문서는 아이디어 목록이 아니라, 현재 TAGO 카탈로그와 대조할 입력값이다.

## 판정 규칙

- **노선번호 존재**와 **실제 경로 가능**을 분리한다.
- 현재 TAGO 방향 순서가 있고, 출발·도착 정류장과 방향이 맞을 때만 앱의 실제 경로로 승격한다.
- 정류장 사이 300m 이내 도보는 연결 노드로 취급하지만, 300m를 넘는 도보는 별도 도보 구간으로 표시한다.
- 과거 여행기는 현재 시간표를 대체하지 않는다. 날짜·운행 여부·환승 성공률은 별도 근거가 필요하다.

자동 검증은 노선번호의 현재 카탈로그 존재 여부만 판단한다. `HYDRATED`라고 표시되어도 시간표·정류장 방향까지 일치한다는 뜻은 아니므로, 실제 검색은 사용자가 선택한 정류장 ID로 `POST /api/journeys/generate`를 다시 실행한다.
